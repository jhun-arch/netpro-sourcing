A CLEARER WAY TO MOVE FORWARD

Five steps, with the details in view.

Some projects begin with finished artwork; others start with a product idea. We clarify what is known, identify the gaps and confirm the important details before production moves ahead.

01 / Product

Choose a product.

Start with the item, who it is for and how it will be used. Add an estimated quantity, target date and delivery destination if you have them.

Explore product categories ↗

02 / Artwork

Share artwork or references.

Send print-ready files when available. A sketch, existing sample, photo or written description can also help explain the direction.

Review customization options ↗

03 / Specification

Confirm the specification.

Work through materials, colors, sizing, decoration, packaging, quantity and timing. Keep the final choices together so the sample can be checked against them.

Prepare a product brief ↗

04 / Sample

Review and approve a sample.

Compare the sample with the agreed specification. Note any changes in one place and confirm the approved version before production begins.

See project support ↗

05 / Delivery

Coordinate production and delivery.

Once the specification is approved, coordinate production follow-up, quality checks and shipping arrangements against the project plan.

Talk through your timing ↗
