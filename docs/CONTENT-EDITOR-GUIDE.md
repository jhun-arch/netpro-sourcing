# 全站内容编辑指南

本指南用于实验站全站 CMS 的内容编辑。全站页面与目录模型已进入代码并通过本地构建。首页、37 个内页、共享设置和目录均已连接真实 Sanity，98 个内容文档通过官方校验；全站新 Preview 与最终浏览器验收仍待主代理完成。因此，先将当前发布状态视为“待验收”，不要仅凭下面的地址认定新功能已经上线。

- [实验 Preview](https://netprosourcing-git-experiment-nextjs-sanity-junhil.vercel.app)
- [Sanity Studio](https://netprosourcing-git-experiment-nextjs-sanity-junhil.vercel.app/studio)

稳定 alias 是实验分支地址；当前它可能仍服务于较早的首页试点版本。请等主代理确认全站版本已验收后再用它编辑或发布全站内容。此项目连接隔离 Sanity project `5mntophk`，dataset 名称为 `production`，不代表正式站数据。

## 进入 Studio

登录后，在“内容管理”中选择：

- “页面管理”→“首页”：维护现有首页内容。
- “页面管理”→“其他页面”：选择固定旧 URL 对应的页面。
- “产品管理”：维护目录产品。
- “产品分类”：维护商品筛选分类和分类横幅。
- “定制款式入口”：维护商品页的款式参考卡片。
- “全站设置”：维护已登记的共享导航和非首页页脚。

页面路由、产品/分类/款式的稳定编号，以及页面模块和内容槽位均由系统维护。新路由、模块和字段绑定需要工程变更；普通编辑者不需要也不应改技术身份字段。

## 编辑首页与其他页面

首页继续使用已有的“首屏”“产品分类”“合作流程”等中文分组。其他页面在“页面内容”中按固定模块编辑文字、图片或链接；“搜索与分享”可维护页面标题、搜索摘要和社交分享信息。

模块、槽位、标题行数和模板顺序是固定的。直接修改可见文字或对应链接即可；不要尝试新增、删除、复制、重排模块，也不要把 HTML、CSS、脚本、选择器或 DOM 标记粘贴进内容字段。需要改变版式或新增页面时请交给开发维护者。

页面原始 URL 是固定身份。改页面标题不会改变路由；首页的页脚在首页文档中维护，其他页面的共享页脚由“全站设置”维护。

## 管理商品

“产品管理”中可编辑产品名称、说明、主图和悬停图、颜色标记、当前尺码、定制入口、分类和显示顺序。“稳定产品编号”由系统生成且只读，不能改名或重建。产品详情继续使用 Shop 中的现有弹窗，不新增独立产品详情 URL；产品 schema 没有独立 SEO 字段，搜索/分享内容由 Shop 页面和 sitePage 页面模型维护。

新建产品时，“当前可选尺码”和“历史询价尺码”默认都是 `One size`。发布前请将当前尺码改成真实可选规格。添加新尺码时，先把它加入“历史询价尺码”，再加入“当前可选尺码”。历史列表会保留导入时、当前以及曾发布过的尺码；不要删除旧值，否则浏览器里保存的历史询价可能无法继续验证。已有目录产品的导入尺码保持源站值，不会用新产品默认值替换。

商品暂时不销售时，在“上架与归档”中关闭“上架显示”。归档会让商品离开公开目录，但保留稳定身份和历史询价校验所需的数据。不要删除商品、复制商品或取消发布；这些操作在 Studio 中受限。

“定制页面链接”和“外部定制链接”是可选项。没有配置链接时，对应定制 CTA 会保持隐藏；有链接时先检查它指向正确的现有定制页面或获批外部网址。

## 管理分类与款式卡

在“产品分类”中维护分类名称、风格卡片分组标题、分类横幅、是否显示风格参考卡片、顺序和上架状态。新分类的稳定编号自动生成，无需编辑者写代码。新增分类后应检查产品归属、筛选名称、横幅和风格参考区域是否都正确。

在“定制款式入口”中维护卡片名称、所属分类、目标页面链接、图片和显示顺序，并可通过“上架显示”归档卡片。稳定款式编号自动生成且不可编辑。

原站导航和款式卡链接使用固定 URL。为保持旧导航兼容，编辑现有卡片时保留其原有 `.html` 目标；不要把旧链接改成仅供内部使用的标签或猜测的新路由。CMS 款式卡仍按其链接导航，既有固定导航入口继续使用代码登记的链接。新增 CMS 分类/款式不等于自动增加一个主导航入口；要增加固定导航项时请由维护者同步代码绑定。

## 图片替换与原图回退

图片字段可以从素材库选择，也可以上传新图，并在 Sanity 图片编辑器中设置裁剪和焦点。若保留导入内容但没有替换 CMS 图片，页面继续使用原站图片及其原始显示比例/位置；补传或替换为新的 Sanity 图片后，改用该图片的裁剪/焦点，并按新图的常规显示方式呈现。此回退适用于目录主图、悬停图、分类横幅和款式卡图片，也适用于页面图片槽位。

替换后检查桌面与移动裁切。页面图片使用同一内容项的“替代文本”；目录图片优先使用图片字段内的“替代文本”，未填写时沿用导入的替代文本。不要编辑隐藏的素材编号、图片比例、位置或插画技术字段。

## 草稿、预览与发布

先保存为草稿，在预览中逐项核对文字、图片裁切、链接和页面布局；确认后才发布。发布只会影响连接到此隔离 Sanity 项目的实验站，不会发布 Production。全站新版本的真实预览流程仍待主代理验收。

草稿自动刷新已知不稳定。若预览没有显示刚保存的内容，等待绿色原生提示“草稿已更新，点击更新预览”出现后点击，并再次确认内容已更新。该后备刷新曾在较早的首页试点 Preview 中通过真实 iframe 验证，但全站新版本尚未重新完成浏览器验证；不要把它描述成全站刷新已经验收。若首次连接失败，可尝试 Presentation 的“重试”，并在发布前确认预览实际显示当前草稿。
