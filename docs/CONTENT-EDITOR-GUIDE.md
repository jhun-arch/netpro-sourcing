# 首页内容编辑指南

这份指南面向首页内容编辑者。当前 Studio 只管理隔离实验站的首页；发布不会修改正式站。登录入口在稳定 Preview 地址后加 `/studio`：

`https://netprosourcing-git-experiment-nextjs-sanity-junhil.vercel.app/studio`

## 找到首页

登录后选择“内容管理”→“页面管理”→“首页”。在编辑区域顶部选择“首屏”“产品分类”“合作流程”“联系与常见问题”等分组；首屏标题和轮播图片都在“首屏”分组。

## 编辑文字和图片

点击文字字段即可修改。替换图片时点击图片字段，从素材库选择已有图片或上传本地图片；图片选择器中可以调整裁剪和焦点。更换或裁剪后，请检查预览中的图片构图。图片有替代文字字段时，请填写准确、简短的描述。

也可以打开“可视化编辑”，开启“编辑”后点击预览中的文字或图片定位对应字段；关闭“编辑”可测试网页按钮、合作流程和 FAQ 的正常交互。若预览提示无法连接或仍在加载，点击“重试”。修改草稿后，如果预览没有自动更新，等待绿色链接“草稿已更新，点击更新预览”出现并点击。脚本自动刷新仍不稳定；发布前请确认预览实际显示了草稿内容。

## 草稿和发布

在独立预览页面中，把指针移到文字或图片，点击出现的“Open in Studio”，会打开对应的后台字段。如果打开的是“已发布”只读版本，先切换到“草稿”再编辑。轮播图片可在显示时点选，也可在后台“首屏 → 轮播图片”中选择。

编辑先保存为草稿，访客仍看到已发布的版本。确认草稿内容后，在首页文档中点击“发布”，才会更新实验站的公开首页。

## 还原历史版本

在首页文档顶部切换到“已发布”，点击编辑器底部的“最后发布”，打开“历史”标签并选择需要的旧版本，再点击“还原”并确认。还原会生成草稿；切回“草稿”检查内容，再点击“发布”才会更新实验站。

Sanity Free 计划保留最近 3 天的历史记录。更久的记录会随着历史清理而不可用，详情见 [Sanity 官方 History experience 说明](https://www.sanity.io/docs/user-guides/history-experience)。本项目已通过 Studio 原生流程还原旧发布版本；还原会生成草稿，需要检查并再次发布。

## 范围

此 Studio 只管理首页试点。其他 38 个旧 `.html` 页面仍为静态页面，尚未迁移到 CMS；请勿把本指南中的发布操作理解为正式站发布。
